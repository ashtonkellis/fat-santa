# fat-santa — card art brief

Please generate **one illustration per card** listed below (83 cards total). Hand this whole file to the image model.

## Style (apply to every image)

- Playful, whimsical **Christmas storybook** illustration — a cohesive set, the same style across all cards.
- Bright, warm festive palette (reds, greens, gold, snow white); soft shading.
- A single clear subject, centered, on a simple / uncluttered background.
- **No text, letters, numbers, or logos anywhere in the image.**
- Portrait orientation, **1024 × 1536 px**, PNG.

## Output file names (IMPORTANT)

- Save each image as a **PNG** using the exact `filename` given for that card.
- File names are all lowercase, words separated by hyphens, no spaces or punctuation (e.g. `Santa's Piggy Bank` -> `santas-piggy-bank.png`).
- Put every file in one folder named `card-art/`.
