# fat-santa — flip-chart art brief

Art for the **flip-chart tracker** (Cities & Knights–style progression book). Three
resource tracks, each with two kinds of card:

- **Quality ladder (6 cards):** the same resource shown at increasing quality,
  level 1 (junk) → level 6 (the dream version).
- **Count cards (5 cards):** 1, 2, 3, 4, 5 of the resource, so the quantity is
  unmistakable at a glance.

Money is **not** tracked here (coins are spent each turn), so the three tracks are
**Present, Reindeer, Sled**. Total: **33 images** (3 × [6 quality + 5 count]).

## Style (apply to every image)

- Playful, whimsical **Christmas storybook** illustration — one cohesive set, the
  same style across all cards (match the existing `card-art/` look).
- Bright, warm festive palette (reds, greens, gold, snow white); soft shading.
- A single clear subject, centered, on a simple / uncluttered background.
- **No text, letters, numbers, or logos anywhere in the image** — on the count
  cards the quantity must be shown by the *number of objects*, never a numeral.
- **Square** orientation, **1024 × 1024 px**, PNG (cards are 2.5 in square).

## Output file names (IMPORTANT)

- Save each image as a **PNG** using the exact `filename` given.
- All lowercase, hyphen-separated, no spaces or punctuation.
- Put every file in one folder named `flip-chart-art/`.
